# Repositorio de Retos de Automatización - Riwi

Este repositorio contiene los ejercicios y retos de automatización propuestos para los coders de Riwi a lo largo de varias semanas.

## Estructura del Repositorio

- [Semana 1: Identificación y Planeación](semana-1/README.md)
  - Identificación de problemáticas.
  - Definición de soluciones en célula.
  - Gestión de proyecto (Scrum).

- [Semana 2: Integración LLM y Ceremonias Ágiles](semana-2/README.md)
  - Reuniones con el cliente y afinamiento del Backlog.
  - Conexión a LLM (DeepSeek / OpenAI).
  - Dailys y buenas prácticas.

- [Semana 3: Automatización con n8n](semana-3/README.md)
  - Implementación de flujos de trabajo con n8n.
  - Integración de componentes para solucionar la dolencia.

Selecciona la semana en la que te encuentras trabajando para revisar los requisitos completos del desafío.
