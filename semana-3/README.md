# Reto de Automatización: Semana 3 - Riwi

## Objetivo
Implementar flujos de trabajo automatizados para el proyecto usando n8n, conectando las diferentes partes de la solución para lograr una verdadera automatización de la "dolencia" inicial.

---

## Requisitos del Desafío

### 1. Workflow de Automatización con n8n
- Diseñar e implementar un workflow utilizando n8n.
- Este flujo debe encargarse de automatizar por lo menos una parte crítica de la solución del proyecto identificada en las semanas anteriores.
- Asegurarse de que el flujo se integre correctamente con el resto de los componentes del proyecto (incluyendo la conexión previa al LLM si aplica).

### 2. Documentación del Flujo
- Exportar el workflow de n8n o tomar capturas de pantalla de la estructura del mismo.
- Explicar en la documentación cómo el flujo en n8n soluciona el problema específico de automatización y qué nodos o integraciones utiliza.

### 3. Dinámica Inicial Mantenida
- Continuar con las ceremonias ágiles (Daily Scrum).
- Mantener la comunicación fluida con el cliente y reuniones periódicas para validación.
- Asegurar que el equipo siga manteniendo sus roles.

---

## Entregables
1. Código, capturas de pantalla o exportación (JSON) del workflow en n8n dentro del repositorio.
2. Documentación actualizada explicando la infraestructura del flujo automatizado.
3. Código fuente actualizado de toda la solución en este repositorio.

¡Sigan con el buen trabajo!
