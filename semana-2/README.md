# Reto de Automatización: Semana 2 - Riwi

## Objetivo
Continuar con el desarrollo de la solución propuesta en la Semana 1, afinando requerimientos con el cliente, implementando automatización inteligente con LLMs e integrando prácticas ágiles avanzadas.

---

## Requisitos del Desafío

### 1. Afinamiento de Backlog con el Cliente
- El equipo (célula) debe tener reuniones formales con el cliente (o quien haga sus veces).
- Refinar y priorizar las tareas del Backlog de acuerdo a la retroalimentación obtenida en estas reuniones.

### 2. Integración con LLM en Desarrollo
- Establecer dentro de sus entornos de desarrollo la conexión a un LLM (puede ser DeepSeek o OpenAI).
- Esta conexión debe estar preparada para integrarse en la arquitectura de la solución automatizada del proyecto.

### 3. Ceremonias Ágiles
- Empezar oficialmente con las ceremonias de Daily Scrum (Daily Stand-up).
- Todo el equipo debe participar reportando: qué hicieron, qué van a hacer y qué bloqueos tienen.

### 4. Preparación de Exposiciones
- Realizar la repartición de temas dentro del equipo.
- Definir buenas prácticas para las exposiciones del clan.

### 5. Validación de la Idea
- Validar la idea de solución tanto con el equipo como con el cliente para asegurar que se está construyendo el producto correcto.

---

## Entregables
1. Evidencia de la conexión al LLM en el entorno de desarrollo (código fuente actualizado en el repositorio).
2. Backlog actualizado y priorizado en el Tablero de Proyectos de GitHub tras la reunión con el cliente.
3. Actualización de este README con el registro de sus ceremonias Daily.

¡Mucho éxito en esta segunda semana!
